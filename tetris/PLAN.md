# 브라우저 테트리스 웹페이지 구현 계획

## 목표

별도 설치나 서버 실행 없이 `index.html` 파일을 브라우저에서 열어 바로 플레이할 수 있는 간단한 테트리스 웹페이지를 만든다. 깔끔한 게임 UI와 데스크톱·모바일 조작을 제공한다.

## 기술 방향

- HTML, CSS, 바닐라 JavaScript만 사용한다.
- 외부 라이브러리와 빌드 도구는 사용하지 않는다.
- `index.html`, `style.css`, `script.js`로 역할을 분리한다.

## 화면 구성

1. 상단에 게임 이름과 짧은 안내 문구를 배치한다.
2. 중앙에 10열 × 20행 게임 보드를 표시한다.
3. 보드 옆 패널에 점수, 최고 점수, 레벨, 삭제한 줄 수를 표시한다.
4. 다음에 등장할 블록을 미리 보기로 표시한다.
5. 시작, 일시정지, 재시작 버튼과 키보드 조작 안내를 제공한다.
6. 모바일에서는 터치 조작 버튼을 보드 아래에 표시한다.

## 게임 로직

1. 7종 테트로미노의 모양과 색상을 정의한다.
2. 빈 보드 배열을 만들고 무작위 블록을 생성한다.
3. 좌우 이동, 회전, 아래 이동, 즉시 낙하의 충돌을 판정한다.
4. 더 이상 아래로 이동할 수 없는 블록은 보드에 고정한다.
5. 가득 찬 행을 제거하고, 행 수에 따라 점수와 레벨을 갱신한다.
6. 레벨이 오를수록 자동 낙하 간격을 줄인다.
7. 새 블록이 시작 위치에 놓일 수 없으면 게임 오버 상태로 전환한다.

## 조작 방식

| 동작 | 키보드 | 모바일 버튼 |
| --- | --- | --- |
| 왼쪽 이동 | `←` | 왼쪽 |
| 오른쪽 이동 | `→` | 오른쪽 |
| 빠른 낙하 | `↓` | 아래 |
| 회전 | `↑` | 회전 |
| 즉시 낙하 | `Space` | 즉시 낙하 |
| 일시정지 | `P` | 일시정지 |

## 디자인 원칙

- 어두운 배경과 밝은 게임 블록으로 시인성을 확보한다.
- 게임 보드와 정보 패널을 카드 형태로 구분한다.
- 버튼에는 호버·포커스·비활성 상태를 명확히 표현한다.
- 작은 화면에서는 패널과 버튼을 세로로 재배치한다.
- 색상만으로 상태를 구분하지 않고 텍스트와 아이콘을 함께 사용한다.

## 검증 항목

1. `index.html`을 직접 열었을 때 게임이 시작되는지 확인한다.
2. 모든 조작 키와 모바일 버튼이 정상 동작하는지 확인한다.
3. 블록 충돌, 회전, 줄 삭제, 점수 계산을 확인한다.
4. 게임 오버 후 재시작이 초기 상태로 돌아가는지 확인한다.
5. 데스크톱과 모바일 너비에서 레이아웃이 깨지지 않는지 확인한다.
