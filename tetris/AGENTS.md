# 프로젝트 작업 지침

## 프로젝트 개요

이 프로젝트는 별도 설치나 서버 없이 브라우저에서 바로 실행되는 정적 테트리스 웹페이지다. 데스크톱과 모바일에서 모두 플레이할 수 있는 깔끔한 게임 경험을 제공한다.

## 기술 기준

- HTML, CSS, 바닐라 JavaScript만 사용한다.
- 외부 라이브러리, 프레임워크, 빌드 도구를 추가하지 않는다.
- 역할을 `index.html`, `style.css`, `script.js`로 분리한다.
- 브라우저에서 `index.html`을 직접 열어 동작해야 한다.

## UI 기준

- 10열 × 20행 게임 보드를 중심에 배치한다.
- 점수, 최고 점수, 레벨, 삭제한 줄 수와 다음 블록 미리 보기를 제공한다.
- 시작, 일시정지, 재시작 버튼과 키보드 조작 안내를 포함한다.
- 모바일에서는 보드 아래에 터치 조작 버튼을 제공한다.
- 어두운 배경과 선명한 블록 색상을 사용해 시인성을 유지한다.
- 버튼의 호버, 포커스, 비활성 상태를 명확히 표시한다.
- 작은 화면에서는 정보 패널과 버튼을 세로로 재배치한다.
- 색상만으로 상태를 전달하지 말고 텍스트 또는 아이콘도 함께 사용한다.

## 게임 로직 기준

- 7종 테트로미노의 생성과 다음 블록 미리 보기를 구현한다.
- 좌우 이동, 회전, 빠른 낙하, 즉시 낙하의 충돌을 정확히 판정한다.
- 블록 고정, 완성 행 제거, 점수·레벨 갱신, 낙하 속도 증가를 처리한다.
- 시작 위치에 새 블록을 둘 수 없으면 게임 오버로 전환한다.
- 키보드 조작은 방향키, `Space`, `P`를 지원한다.

## 검증 기준

- 직접 연 `index.html`에서 게임이 시작되어야 한다.
- 키보드와 모바일 조작이 모두 정상 동작해야 한다.
- 회전, 충돌, 줄 삭제, 점수 계산, 게임 오버, 재시작을 확인한다.
- 데스크톱 및 모바일 너비에서 레이아웃이 유지되어야 한다.
